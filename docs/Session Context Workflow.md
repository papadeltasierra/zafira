# Session Context Workflow

This repository uses `SESSION_CONTEXT.md` as the single resume file for future work sessions.

## When To Update

- At the start of a session: set `Last updated`, `Current focus`, and `Next Actions`.
- During work: add concise notes only for meaningful changes.
- At session end: update `Decisions Log`, `Blockers`, and `Handoff Checklist`.

## Update Style

- Keep notes short and factual.
- Include dates for decisions.
- Include exact file paths when relevant.
- Prefer command outcomes over raw logs.

## Suggested Entry Format

- `[YYYY-MM-DD] <short outcome>`
- Optional: `Next: <single best next step>`

## Example

- `[2026-08-02] Added BLE reconnection guard in main/ble_endpoint.c.`
- `Next: Run firmware build and verify reconnect timing.`
